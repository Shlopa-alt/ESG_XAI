# Словарь названий

Одно понятие — одно слово на всех экранах и в инструкции. Читатель никогда не работал с ИИ и экономикой.
Меняются только слова на экране: коды (`EXP-001`, `CR-01`, `H-001`, `DS-01`), API, поля и адреса страниц остаются.
Новый термин сначала сюда, потом на экран. Точные термины живут в блоках «Подробнее» и в `docs/SPEC.md`.

| Внутреннее название (код, ТЗ) | На экране | Как объяснить |
|---|---|---|
| База знаний, KBRAG | Банк статей | Научные статьи, на которые мы опираемся |
| Граф связей | Карта связей (вкладка банка) | Что статьи говорят о связях между понятиями |
| Сводка фактов KBRAG по пункту методики | Что говорят статьи (вкладка «Методики») | Сколько статей банка говорят, что фактор повышает результат, снижает его или не влияет, с цитатами |
| Источник связи (src факта) | Фактор | Что влияет: понятие, от которого идёт связь |
| Цель связи (dst факта) | Результат | На что влияет: понятие, к которому идёт связь |
| Согласие статей | Статьи согласны / расходятся | Доля самого частого ответа среди «повышает / снижает / не влияет»; от 75 % — «в основном согласны» |
| Сущность | Понятие | Показатель или явление на карте. Частые понятия показаны по-русски: `frontend/src/concepts.ts` |
| Импорт статьи | Добавить статью | Загрузить PDF или указать DOI |
| Ветка базы | Тема | Раздел банка: рейтинги, финансы, Россия и другие |
| Гипотеза | Идея для проверки | Утверждение, которое можно проверить расчётом. Слово «гипотеза» — один раз в пояснении |
| effect + target_kind гипотезы | Тип связи | Как фактор влияет (повышает, снижает, не влияет, по-разному) и на какие показатели: финансовые или нефинансовые результаты |
| weight гипотезы (вес связи) | Сила связи | Насколько заметно влияние: 1 — слабая, 2 — средняя, 3 — сильная. Ставит автор идеи, изменить может рецензент или владелец |
| Опора | Источник | Цитата из статьи, на которой держится идея |
| Эксперимент | Проверка | Расчёт и отчёт: подтвердилась ли идея |
| Запуск | Расчёт | Программа считает результат на данных |
| Датасет | Набор данных | Таблица показателей компаний или регионов |
| Срез | Версия данных | Файл данных на определённую дату, больше не меняется |
| Таблицы из статей, черновики | Данные из статей | Таблицы, найденные в статьях банка; условия использования определяет статья |
| Методология, методика | Методика | Что изучает лаборатория и по каким правилам |
| Узел методики | Пункт | Направление, вариант, задание или раздел |
| CR | Предложение изменить методику | Методика меняется только с основанием и после рецензии. Код `CR-01` остаётся |
| Анализ данных, `/analysis` | Анализ данных | Выбрать, что изучаем, и набор данных — платформа подберёт метод или нейросеть и запустит расчёт |
| Шаблон, метод библиотеки | Метод | Готовый расчёт платформы; новые методы пишут люди |
| Нейросеть, архитектура (MLP, трансформер) | Нейросеть: перцептрон, трансформер | Модель, которая учится предсказывать показатель по данным |
| Тип задачи | Тип задачи | Что нужно получить: прогноз показателя, согласованность, класс, прогноз по годам… |
| «Как у авторов» | Как у авторов | Повтор расчёта с той же нейросетью, что в статье-источнике |
| Оценка ресурсов | Цена расчёта | Где посчитается и сколько минут займёт — видно до запуска |
| Агент сбора данных | Поиск данных по ссылкам из статей | ИИ-помощник находит в статьях ссылки на данные и скачивает доступное |
| Qwen | ИИ-помощник | Предлагает идеи и пишет черновики, решают люди. «Qwen» остаётся на служебной странице |
| owner | Администратор | Роль с правом принимать изменения методики и выдавать доступы |

Слово «Рецензия» остаётся: другой человек проверяет работу, прежде чем её примут.
