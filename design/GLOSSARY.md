# Словарь названий

Одно понятие — одно слово на всех экранах и в инструкции. Читатель никогда не работал с ИИ и экономикой.
Меняются только слова на экране: коды (`EXP-001`, `CR-01`, `H-001`, `DS-01`), API, поля и адреса страниц остаются.
Новый термин сначала сюда, потом на экран. Точные термины живут в блоках «Подробнее» и в `docs/SPEC.md`.

| Внутреннее название (код, ТЗ) | На экране | Как объяснить |
|---|---|---|
| База знаний, KBRAG | Банк статей | Научные статьи, на которые мы опираемся |
| Граф связей | Карта связей (вкладка банка) | Что статьи говорят о связях между понятиями |
| Сущность | Понятие | Показатель или явление на карте |
| Импорт статьи | Добавить статью | Загрузить PDF или указать DOI |
| Ветка базы | Тема | Раздел банка: рейтинги, финансы, Россия и другие |
| Гипотеза | Идея для проверки | Утверждение, которое можно проверить расчётом. Слово «гипотеза» — один раз в пояснении |
| Опора | Источник | Цитата из статьи, на которой держится идея |
| Эксперимент | Проверка | Расчёт и отчёт: подтвердилась ли идея |
| Запуск | Расчёт | Программа считает результат на данных |
| Датасет | Набор данных | Таблица показателей компаний или регионов |
| Срез | Версия данных | Файл данных на определённую дату, больше не меняется |
| Таблицы из статей, черновики | Данные из статей | Таблицы, найденные в статьях банка; условия использования определяет статья |
| Методология, методика | Методика | Что изучает лаборатория и по каким правилам |
| Узел методики | Пункт | Направление, вариант, задание или раздел |
| CR | Предложение изменить методику | Методика меняется только с основанием и после рецензии. Код `CR-01` остаётся |
| Qwen | ИИ-помощник | Предлагает идеи и пишет черновики, решают люди. «Qwen» остаётся на служебной странице |
| owner | Руководитель | Роль с правом принимать изменения и выдавать доступы |

Слово «Рецензия» остаётся: другой человек проверяет работу, прежде чем её примут.
