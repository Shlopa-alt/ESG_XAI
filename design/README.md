# Макеты экранов

Файлы `*.dc.html` — исходники макета из Claude Design. Это референс, а не рабочий код:
они не открываются в браузере напрямую (нужен рантайм редактора). Использовать как спецификацию
вёрстки: структура блоков, тексты, состояния, данные-примеры в `renderVals()`.

Порядок: Main → Knowledge → Graph → Experiments → Experiment → Run → Methodology.

## Токены

| Токен | Значение | Где |
|---|---|---|
| `--bg` | `#F4F6F3` | фон страницы |
| `--surface` | `#FFFFFF` | карточки, панели |
| `--border` | `#DDE3DF` | рамки |
| `--text` | `#17201B` | основной текст |
| `--text-muted` | `#5A6B62` / `#47564D` | вторичный текст |
| `--sidebar` | `#14231C` | боковое меню |
| `--accent` | `#1F6F4A` (hover `#17583A`) | кнопки, ссылки, акценты |
| `--warn` | `#B5651D` | подсветка выбранных связей |

Статусы (фон / текст): завершён `#DCEFE3/#145A37`, в работе `#DCE8F7/#1D4E89`,
на проверке `#FBE8D0/#8A4A0F`, запланирован `#ECEEEC/#4A554F`.

Шрифты: IBM Plex Sans (интерфейс), IBM Plex Mono (коды, метрики, логи). Радиусы: 8 px кнопки, 12 px карточки.
Сетка: боковое меню 240 px + контент с max-width 1180 px, на мобильном меню уходит наверх.
