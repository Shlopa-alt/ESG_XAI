# Первый промпт для Claude Code

Скопировать в Claude Code после открытия папки проекта:

---

Прочитай CLAUDE.md, docs/SPEC.md и design/README.md. Начинаем этап 1 из раздела «Этапы».

1. Предложи план этапа 1 списком задач и дождись моего подтверждения.
2. После подтверждения создай каркас: backend (FastAPI + SQLAlchemy + Alembic), frontend (Vite + React + TS),
   deploy/docker-compose.yml с postgres, redis, mlflow, backend, frontend, nginx и .env.example.
3. Сделай модели User и роли, миграцию, вход через LDAP (с заглушкой для локальной разработки, включаемой переменной окружения).
4. Сверстай общий layout с боковым меню по design/Main.dc.html и пустые страницы для всех разделов.
5. Тесты: проверка ролей и логина. В конце покажи, как всё поднять одной командой.

Не придумывай данные: сиды только из раздела 8 SPEC.md.
