# esg — командная строка ESG Open Research

Работа с платформой без сайта и «ручной режим»: в любой момент взять данные или расчёт в свои руки —
в Jupyter или в своём коде. Только стандартная библиотека Python 3.11+.

## Установка

```bash
python -m pip install ./cli          # из клона репозитория
esg login --url https://<адрес платформы>
```

Логин и пароль — те же, что на сайте. Пароль вводится в терминале и не сохраняется; сохраняется только
cookie сессии в `~/.esg/cookies.txt` (папку можно сменить переменной `ESG_HOME`, адрес — `ESG_URL`).

Для скриптов и серверов — личный токен открытого API (сайт → «Доступ к API», подробно —
`docs/API.md`): `esg login --token --url https://<адрес>` (токен вводится в терминале и хранится в
`~/.esg/token`) или переменная `ESG_TOKEN`. Токен «только чтение» не запускает расчёты.

## Взять работу в свои руки

```bash
esg notebook --run 57 -o work/          # расчёт: ноутбук, данные, код метода, параметры, итоги платформы
esg notebook --snapshot 12 -o work/     # версия данных: файл и ноутбук для ручной обработки
esg download 12 -o data/                # только файл версии данных (sha256 сверяется)
```

Ноутбук проверяет sha256 данных, повторяет расчёт той же командой, что исполнитель платформы, сверяет
итоги с записанными и оставляет место для своего кода. Файлы наборов под NDA — только допущенным
(правило 6): в архиве их тогда нет, это сказано в `README.txt`.

## Данные и расчёты

```bash
esg datasets                     # наборы данных
esg dataset DS-09                # версии набора: номер версии — для download и launch
esg templates                    # методы и их параметры
esg estimate correlation-scan --snapshot 12 --param method=partial
esg launch correlation-scan --snapshot 12 --experiment EXP-010 --param method=partial
esg runs --experiment EXP-010
esg run 57                       # статус, параметры, итоги (--json — всё)
```

Параметры: `--param имя=значение`, значение — JSON, если читается (`columns='["a","b"]'`, `holdout=50`,
`true`), иначе строка; или все сразу — `--params-json params.json`. Лимиты и квоты те же, что на сайте.

## Свой расчёт — в реестр

```bash
esg upload-run EXP-010 results/20261116-120000/run.json
```

В реестр попадает только воспроизводимый расчёт (правило 3): в `run.json` должен быть коммит
репозитория. Расчёт, повторённый в распакованном архиве, коммита не имеет — повторите его в клоне
репозитория на нужном коммите (`git checkout <коммит>`, затем `python runner/methods/<метод>.py …`).
